# Diario di Barovia

Diario di campagna di Curse of Strahd del nostro gruppo.

Leggilo qui: https://cecio683.github.io/diario-barovia/

## Struttura

- `index.html` — copertina, compagnia e indice delle puntate
- `puntata-NN.html` — un file per ogni puntata
- `css/stile.css` — stile comune
- `js/tavole.js` — tavole disegnate (canvas)
- `img/` — immagini
